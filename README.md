# Computer Vision Lab Experiments

## About
This repository contains practical lab experiments completed as part of the Computer Vision course. The experiments use Python, OpenCV, NumPy, and Google Colab to explore image processing, image transformations, feature detection, and video processing techniques.

## Experiments Covered

- **Image Processing:** Image-to-grayscale conversion and Gaussian blur
- **Edge Detection:** Canny Edge Detection
- **Histogram Processing:** Histogram Equalization and Colour Histogram
- **Morphological Operations:** Image Erosion
- **Geometric Transformations:** Image Rotation (90°, 180°, and 270°) and Affine Transformation
- **Video Processing:** Slow Motion and Fast Motion effects

## Technologies Used
- **Programming Language:** Python
- **Libraries:** OpenCV, NumPy, Matplotlib
- **Platform:** Google Colab
- **Version Control:** Git and GitHub
